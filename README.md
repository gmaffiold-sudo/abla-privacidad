# Política de privacidad de Abla

Este repositorio contiene **una sola página**: la política de privacidad de la aplicación
Abla, publicada con GitHub Pages porque Google Play exige una URL pública.

Aquí **no hay código fuente**, y es a propósito: el repositorio del proyecto contiene la
clave de firma de la aplicación y no puede hacerse público.

Para actualizar la política, edita `index.html` y haz commit. GitHub Pages la republica sola
en un minuto.
